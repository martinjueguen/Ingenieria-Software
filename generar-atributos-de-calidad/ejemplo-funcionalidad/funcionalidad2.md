El sistema deberá permitir a un usuario registrado completar el proceso de compra de un producto, desde la selección hasta la confirmación del pedido, validando correctamente el stock disponible y los datos de pago ingresados.

1. Fuente: Usuario registrado
2. Estímulo: Inicio del proceso de compra (agregar producto al carrito y confirmar pedido)
3. Ambiente: Operación normal del sistema
4. Artefacto: Módulo de carrito de compras y procesamiento de pedidos
5. Respuesta: El sistema valida stock, procesa el pago y genera la confirmación del pedido correctamente
6. Medida de la Respuesta: 100% de los pedidos válidos se confirman correctamente, con 0 errores de validación de stock o pago en condiciones normales
7. Tipo escenario: funcionalidad
